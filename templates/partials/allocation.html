{{ icon('chev', 'explain__mark') }}What does this mean?

Every call this app makes to YouTube spends units from a daily allowance Google gives your own Cloud project for free. There is nothing to buy and nothing to pay: the allowance is {{ '{:,}'.format(allocation.limit) }} units a day, it costs 50 units to add one video to a playlist and 1 unit to read a page of the channel, and it refills by itself. That is roughly {{ '{:,}'.format(allocation.videos_per_day) }} videos a day — which is why a large channel is copied across several days rather than in one run. What is left today covers about {{ '{:,}'.format(allocation.videos_affordable) }} more video{{ '' if allocation.videos_affordable == 1 else 's' }}. If Google granted this project more than the free allowance, set it in Google account.

The bar above is this app's own tally, not a reading from YouTube. The API publishes no remaining-quota endpoint, so every figure here is counted locally from the calls this app has made since the last reset. If a second tool shares the same Google Cloud project, its spending is invisible here and the remaining figure will read higher than the truth. The authoritative signal is YouTube itself refusing a call; when that happens the tally is pinned to the limit and the running playlist mirror holds immediately.

The reset is Google's clock, not this app's and not a timer started by your first call: the credits refill at midnight Pacific Time every day. This app prints that moment from the {{ allocation.reset_tz }} timezone, and if that is wrong for your project the wall shown here outlasts the real one. Reset the count, offered on this band whenever the credits read used up, rules today's tally off the moment you press it, so the next playlist mirror puts the question to YouTube rather than to this clock. It resets nothing at Google: if the day really is spent, the first call comes back refused, that playlist mirror holds on it exactly as it does at the wall, and the band reads used up again — one turned-away call, charged no units, is the whole cost of being wrong.

Running out is expected, not a failure. The playlist mirror stops deliberately at the wall, keeps the playlist it already created, and records exactly which videos are in it. After the reset you press Resume and it continues into that same playlist, skipping everything already added — no duplicates, no second playlist, nothing to redo.
